Create a modern, responsive **Online English Learning Web App for Vietnamese learners**, inspired by the user experience, learning flows, and visual concepts of platforms such as **ELSA Speak, Bitu, Kyna English, and NativeX**.

## 1. Project Requirements

Build a **static frontend web application** using only:

* HTML5
* CSS3
* Vanilla JavaScript
* No backend
* No database
* No React
* No Angular
* No Vue
* No TypeScript
* No build tools required

The application must run directly by opening `index.html` in a browser.

Use mock/static data in JavaScript to simulate application behavior.

The UI language should be **English**, but the application must be designed specifically for **Vietnamese users**. Important explanations, learning tips, translations, and error messages can include Vietnamese.

The application should feel like a real commercial English-learning platform rather than a simple demo website.

# 27. UX Requirements

The application should feel like a real product.

Important UX principles:

* Clear CTA
* Minimal unnecessary clicks
* Immediate feedback
* Visible learning progress
* Encourage daily learning
* Keep lessons short
* Make speaking practice easy to start
* Show Vietnamese explanations when useful
* Always show the user's current learning level
* Use consistent buttons and cards
* Show empty states
* Show loading states where appropriate
* Show success/error feedback

Avoid creating a website that looks like a simple admin dashboard.

It should feel like a **consumer EdTech application**.

The overall product should combine:

**ELSA-style pronunciation practice + Bitu-style speaking/classes + Kyna-style Vietnamese education platform structure + NativeX-style modern English-learning experience.**

Build the complete frontend with polished UI, realistic mock data, responsive design, and functional JavaScript interactions.
