# NEXUS ERP — Business Management & Finance Platform

A complete, front-end-only ERP built with **HTML5, CSS3 and vanilla JavaScript (ES6)**. No frameworks, no build step, no backend.

## Run it

Open `index.html` in any modern browser (double-click works — it runs from `file://`).

## How the data stays consistent

Every business document goes through a service in `js/services.js` that applies its side effects:

- **Order → Confirmed** reserves stock and checks the credit limit.
- **Order → Shipped** deducts stock (movement *Sales Delivery*) and raises low-stock alerts.
- **Invoice sent** posts Dr Accounts Receivable / Cr Sales + Tax, and Dr COGS / Cr Inventory.
- **Payment recorded** updates the invoice balance/status, posts Dr Bank / Cr AR, and completes delivered orders.
- **Goods receipt** increases stock (movement *Purchase Receipt*).
- **Supplier invoice** posts Dr Inventory + Input tax / Cr Accounts Payable.
- **Expense paid** posts Dr Expense / Cr Bank.

All journal entries are validated (debits must equal credits), so the balance sheet always balances and the trial balance always nets to zero. The sample data is generated by replaying ~9 months of activity through these same services (`js/data.js`).

## Notes

- **Data** lives in `localStorage` (keys prefixed `nexus_erp_`). *Settings → Data & Backup* can download a JSON backup, restore one, or reset the demo data.
- **Routes** are hash URLs, so any view can be linked, e.g. `#/invoice/INV-2026-00125`, `#/billing?status=open`, `#/inventory?filter=low`, `#/reports?cat=sales&report=sales-month`.
- **Keyboard:** `/` or `Ctrl+K` opens search, `Alt+N` opens notifications, `Esc` closes dialogs. Modals trap focus.
- **Theme:** light/dark is saved per browser.
- **Printing:** documents and reports print as clean pages; *Download* on documents saves a standalone HTML copy (use the browser's *Print → Save as PDF* for a PDF).
- **Emails:** "Send" actions are simulated; nothing leaves the browser.
