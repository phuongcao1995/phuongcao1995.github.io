Create a modern **social networking website** as a static frontend prototype.

### Technology

* Use **HTML, CSS, and vanilla JavaScript only**
* No React, Vue, Angular, Bootstrap, Tailwind, or other frameworks
* No backend or database
* All functionality should work with mock/static data in JavaScript
* The website should run directly by opening `index.html`
* Organize the project cleanly:

  * `index.html`
  * `css/style.css`
  * `js/app.js`
  * `assets/`

### Design Inspiration

Use the best UX patterns from:

* Facebook — news feed, reactions, comments, groups, notifications
* Zalo — clean messaging and Vietnamese-friendly social experience
* Instagram — visual content, stories, profiles, media-focused posts

Do **not** copy their logos, branding, exact UI, or copyrighted visual assets. Create an original social-network identity and design.

### Website Concept

Create an original social network called **"Connect"**.

The design should feel:

* Modern
* Clean
* Fast
* Friendly
* Responsive
* Professional
* Suitable for both desktop and mobile

Use a consistent modern color system, typography, spacing, rounded cards, subtle shadows, and smooth hover/transition effects.

### Responsive Design

The website must work well at:

* Desktop: 1440px+
* Laptop: 1024px
* Tablet: 768px
* Mobile: 375px / 390px / 430px

On mobile:

* Hide or collapse sidebars
* Use bottom navigation where appropriate
* Make the feed full width
* Make stories horizontally scrollable
* Optimize buttons and touch targets
* Ensure there is no horizontal overflow

### Important Requirements

1. Generate the **complete working website**, not just a design mockup.
2. All buttons should have meaningful interactions.
3. Avoid placeholder sections that say "Coming Soon".
4. Do not use external frameworks.
5. Keep HTML, CSS, and JavaScript well organized.
6. Use reusable JavaScript functions instead of duplicating code.
7. Keep the code easy to extend into a real backend application later.
8. Use comments only where they improve understanding.
9. Make the UI visually consistent across all pages/components.
10. Ensure the website works by simply opening `index.html`.
